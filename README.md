# JIW - Landing Page Comercial

Landing page estática da JIW Soluções Tecnológicas.

## Arquivos

- `index.html`: estrutura da página.
- `styles.css`: identidade visual e responsividade.
- `script.js`: navegação e formulário de contato.
- `assets/`: logos, avatar, capa e template visual.

## WhatsApp

Para ativar o botão do formulário, configure a constante `WHATSAPP_NUMBER` em `script.js` com DDI, DDD e número.

Exemplo:

```js
const WHATSAPP_NUMBER = "5599999999999";
```

## Publicação

O projeto pode ser publicado pelo GitHub Pages usando a branch `main` e a pasta raiz.
